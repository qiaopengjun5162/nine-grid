# 演示手册（5 分钟）

> 一句话定位：**九宫棋**——把「规则」本身当交付物的井字棋。规则只写一份，跑在三个宿主上，还能被机器证明。

## 一、开场前 60 秒自检

```bash
cd nine-grid
pg_isready                      # 要 accepting connections
cargo run -p nine-grid-server   # 另开终端，直到打印「打开 http://127.0.0.1:8080」
curl -s localhost:8080/healthz  # 期望 {"status":"ok"}
```

浏览器提前开好四个标签，别在台上找地址：

| 标签 | 地址 | 用途 |
|---|---|---|
| 1 | <http://127.0.0.1:8080/showcase.html> | 12 页介绍稿。`←→`/空格翻页，`N` 讲稿，`F` 全屏，`P` 打印 PDF |
| 2 | <http://127.0.0.1:8080/> | 本地版，能真下 |
| 3 | <http://127.0.0.1:8080/chain.html> | 链上版（要 Phantom + Devnet 币） |
| 4 | <http://127.0.0.1:8080/chain-archive.html> | 链上棋谱馆，只读，不用钱包 |

## 三、现场三分钟四步（对应第 10 页）

1. **开一局**：点「开一局新棋」，拿到 6 位房间码和邀请链接。（30s）
2. **换窗口入座**：无痕窗口打开邀请链接，自动执 X；下三手，看胜线高亮与棋谱逐手增加。（40s）
3. **切主题**：右上角切「星穹会员」，同一份 DOM 只换变量。（10s）
4. **链上**：连 Phantom 建局、入座、落子；再进棋谱馆展开这局，看它从交易历史重建。（60s）

> 单人对局可以省掉第二个窗口：首页选难度 → 「和机器人下一盘」，机器人 1 秒内应招，更适合一个人讲。

## 四、翻车预案

| 症状 | 处理 |
|---|---|
| `pg_isready` 不通 | 起 Postgres；来不及就跳过本地版，直接讲链上版与棋谱馆 |
| Phantom 没装 / 没币 | 只讲第 9 页与棋谱馆，**不要**在台上等水龙头 |
| Devnet RPC 限流 | 刷新一次；仍不行就讲页面结构，别硬等 |
| 链上页白屏 | 依赖走 `esm.sh` CDN，网络抽风会白；演示前先打开一次让它进缓存 |
| 全部网络都挂 | 放 `docs/media/demo-local.webm` 录屏，照讲稿讲 |

两个固定坑：

- **GitHub Pages 只有静态页**：`qiaopengjun5162.github.io/nine-grid` 上的本地版没有后端，点「开一局」会失败。演示一律用 `127.0.0.1:8080`。
- **本地版身份是浏览器自报的**：换浏览器/清缓存就丢了座位，别在台上清缓存。

## 五、三句不要说错的话

1. 别说「上主网了」——是 **Devnet**，测试币；程序 ID `AtRporBXQDCnT5ibxMic5joWwj2qJ6UpoBQgw5Yu4HD6`。
2. 别说「绝对公平」——链上记录不可篡改；**本地版**只适合朋友间玩，身份不是密码学保证的。
3. 别说「零缺陷」——审计里 P1 未修：链上缺认输/超时（对手掉线这局会卡住，租金锁死）、无 Dockerfile、无速率限制。

## 六、被问到时的短答

| 问题 | 回答 |
|---|---|
| 为什么做井字棋？ | 规则一句话说得清，正好用来练「把状态机写对」，以及证明「写对了」这件事。 |
| 和普通井字棋网页差别在哪？ | 规则只有一份实现、三个宿主共用；链上记录不可篡改；规则有 21 条机器证明。 |
| 形式化验证到底有什么用？ | 它逼你把「我以为」写成「在什么前提下成立」。我们就被它纠正过一次：双方同时三连在任意棋盘上是可能的，只在合法对局里不可能。 |
| 能商用吗？ | 现在不能。缺托管部署、审计、主网，还有 P1 项没修。 |
| 代码在哪？ | <https://github.com/qiaopengjun5162/nine-grid>，CI 8 个 job 全绿。 |
