# Phantom 链上版 · 真机测试清单

链上版的**交易构造逻辑**已经用程序化方式验证过（`chain-test.sh` 第 5 步 + devnet 实跑），
但浏览器里 Phantom 的**钱包签名弹窗**没法自动模拟，需要真机手动过一遍。

这份清单就是给那次手动验证用的：照着点，每一步都有「该看到什么」。

---

## 0. 准备（一次性）

1. 装 **Phantom 浏览器扩展**（phantom.app），新建一个测试钱包。**不要用装了大额资产的主钱包测试**。
2. 给测试钱包切到 **Devnet**：
   Phantom → 左上角网络名（默认 Mainnet）→ 选 **Devnet**。
3. 领一点 devnet 测试 SOL（ faucet.solana.com 或 `solana airdrop 1 <你的地址> --url devnet`）。
   建局要付账户租金，约 0.01 SOL，1 SOL 足够玩很久。
4. Phantom 切到 Devnet 后，确认地址栏看到的是 Devnet，不是 Mainnet。

> 想用本地验证器测也行：页面点「切到本地验证器」，Phantom 网络选 **Localhost**，
> 但前提是你本机先跑了 `solana-test-validator` 并部署过程序（见 `scripts/chain-test.sh`）。

## 1. 打开在线版

打开 <https://qiaopengjun5162.github.io/nine-grid/>

**该看到**：
- 标题「链上对局」，一行小字「当前 Devnet · 程序已上公网，钱包切到 Devnet 即可玩」。
- 一个「连接 Phantom 钱包」按钮。
- 没有报警红条（红条出现说明依赖或 RPC 加载失败）。

如果页面显示「没有检测到 Phantom 钱包」→ 扩展没装好或没启用，刷新重试。

---

## 2. 连接钱包

点「连接 Phantom 钱包」→ Phantom 弹窗 → 点「连接 / Approve」。

**该看到**：
- 按钮变成「钱包已连接」，旁边显示你的地址缩写（如 `6MZD…Rpd`）。
- 「建一局（我执 O）」和「入座（执 X）」按钮变为可点。
- 如果 Phantom 不在 Devnet，页面会提示「请把 Phantom 也切到 Devnet」——照做。

---

## 3. 建局

点「建一局（我执 O）」→ Phantom 弹窗显示交易详情 → 点「签名 / Sign」。

**该看到**：
- 状态栏先显示「发送建局交易…」，再变成「建局成功 xxxxxxxx…」。
- 成功后自动进入对局界面，显示一个 PDA 地址（一长串 Base58）和两个座位（O = 你）。
- 状态文字「等对手入座。把 PDA 地址递过去。」

> 这一步验证：`create_game` 指令 + PDA 派生 + Phantom 签名。

---

## 4. 入座（两个办法，任选）

**办法 A · 两个钱包/两个浏览器**：用另一个 Phantom 钱包（或另一个浏览器 profile），
打开页面，在大厅「对局 PDA 地址」框里粘贴上一步的 PDA 地址，点「入座（执 X）」→ 签名。
这一步会发一笔真正的 `joinGame` 交易，成功后进入对局界面。

**办法 B · 邀请链接**：建局方进局后点「复制地址」（复制出来的是带 `?pda=` 的邀请链接），
发给对方；对方打开链接、点「连接 Phantom 钱包」后会自动进入这局的对局界面。
**注意**：进局只是「看」，还没有真正入座——
此时 X 方界面上会出现一个醒目的「入座（执 X）」按钮，点它 → 签名，才发 `joinGame` 交易。
（建局方 O 看不到这个按钮，链上也不允许自己入自己的局。）

**该看到**：
- 入座交易的签名弹窗；状态栏先「发送入座交易…」，再「入座成功 xxxxxxxx…」。
- X 座位从「待入座」变成对方地址缩写，随后「入座」按钮消失。
- 状态文字变成「对局中」，且 O 方显示「轮到你落子（O）」。

> 这一步验证：`join_game` 指令 + 账户订阅刷新。若 X 不点「入座」就落子，格子是灰的、点不动，
> 直接构造交易也会被链上以 `NotAPlayer` 拒绝——这正是「前端不判规则、链上说了算」的体现。

---

## 5. 轮流落子

轮到你时点一个格子 → Phantom 弹窗 → 签名。轮流下，直到分出胜负或平局。

**该看到**：
- 签名确认后棋子立刻出现在格子上（账户订阅 `onAccountChange` 触发刷新）。
- 状态栏显示「落子成功 xxxxxxxx…」和一个「浏览器查看 ↗」链接，点它能在 Solana Explorer 看到这笔交易。
- 不是你回合时，格子是灰的、点不动。
- 三连时高亮获胜线，状态文字显示「O 方获胜 / X 方获胜 / 平局」。

> 这一步验证：`play` 指令 + 轮次/占位/判胜由链上裁决 + 前端只读链上状态。

**顺手试一下拒绝分支**（可选）：不是你回合时点格子、或点已占的格子 —— 应该点不动；
直接用 CLI 构造非法交易会被链上拒绝。这证明「前端不判规则，链上说了算」。

---

## 6. 关局退租金

终局后，**建局方（O）**会看到「关局退租金」按钮，点它 → 签名。

**该看到**：
- 状态栏「已关局 xxxxxxxx…」，界面退回大厅。
- 账户租金退回建局方钱包（Explorer 里能看到 `closeGame` 交易）。

> 这一步验证：`close_game` 指令 + 只有 O 方能关 + 租金回收。

## 7. 已知边界 / 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 连钱包后点建局，Phantom 报「网络不匹配」 | Phantom 网络没切到 Devnet。切过去再试。 |
| 状态栏一直「发送建局交易…」不动 | RPC 卡住，刷新页面重连；或 devnet 拥塞，稍后重试。 |
| 「RPC 不可达」提示 | 页面用的是 `api.devnet.solana.com`，检查网络/代理。 |
| 落子后棋子没出现 | 账户订阅有延迟；状态栏有「浏览器查看」链接可确认交易是否上链。刷新页面也能从链上重新拉取。 |
| 别人的 PDA 进不去 | PDA 地址要复制完整（Base58 一长串），前后别带空格。 |
| Phantom 弹窗点「拒绝」 | 交易不会发出，状态栏显示失败，可重试。 |
